# 🤾 Match des Légendes — TCG Équipe de France

POC de jeu de cartes (TCG) handball pour club, thème Équipe de France.

## Jouer
Site en ligne : **https://ndious.github.io/tcg-hand-equipe-de-france/**

- **Collection** : 16 cartes (10 joueurs, 4 actions, 2 trophées).
- **Duel rapide** : choisis un attaquant, son ATQ affronte la DEF d'un Bleu tiré au sort. Premier à 3 manches.

## Description
Projet de cohésion de club de handball : cartes collectionnables et mini-jeu rapide, pensés pour tous les âges. Voir le design complet du jeu dans le dépôt de design.

## Déploiement
GitHub Pages via GitHub Actions (voir `.github/workflows/pages.yml`). Tout push sur `main` redeploie automatiquement le site.
